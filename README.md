# Avaluatró

Aplicació web inicial per avaluar les competències de secundària a partir d'evidències de proves, projectes i activitats.

## Inici

Com que l'aplicació està dividida en mòduls JavaScript natius, serveix la carpeta des d'un servidor HTTP local (els navegadors no permeten carregar aquests mòduls de manera fiable amb `file://`). No cal instal·lar dependències:

1. Obre un terminal a la carpeta del projecte.
2. Executa `python3 -m http.server 8000`.
3. Visita `http://localhost:8000`.

Atura el servidor amb `Ctrl+C`.

El codi d'arrencada i les accions de l'aplicació es troben a `app.js`. La carpeta `js/` separa la validació i les dades, els càlculs de notes, l'estat, les vistes i els formats compartits. `js/assessment.js` defineix el registre extensible de tipus d'elements avaluatius i la conversió dels seus ítems.

L'exportació dels informes en lot fa servir pdfmake 0.2.20 i fflate 0.8.2, inclosos a `third-party/` amb les llicències corresponents. Es carreguen localment només quan es genera el ZIP.

## Funcionalitats

- El fil d'Ariadna permet tornar als nivells superiors de cada vista. Els botons Enrere i Endavant del navegador recuperen les vistes visitades i el seu context durant la sessió, també després de recarregar la pàgina.
- Crea cursos acadèmics i grups classe anuals amb desdoblaments opcionals. Les matrícules de l'alumnat es conserven per curs; cada alumne també pot pertànyer a diversos grups addicionals.
- Crea assignatures, nivells i seqüències programatives sense assignar-hi cap grup d'alumnes. Les situacions d'aprenentatge contenen activitats i proves amb temporització en hores. Les activitats s'organitzen amb evidències i criteris d'assoliment; les proves, amb preguntes, contribucions per competència i un solucionari per pregunta. Tots dos tipus comparteixen el càlcul de notes i contribucions ponderades per les hores.
- Crea ofertes docents per connectar un nivell programatiu amb grups classe o addicionals d'un curs acadèmic. Només les ofertes del curs vigent presenten alumnat per avaluar; les ofertes i qualificacions d'altres cursos es conserven com a historial. Si canvia una matrícula, les notes ja registrades continuen vinculades a l'oferta on es van obtenir.
- Obre l'assignatura i després la targeta del nivell per consultar-ne el seguiment competencial. El botó «Obre seqüència» porta a una pàgina pròpia on pots afegir situacions d'aprenentatge i incorporar-hi elements avaluatius existents. En editar el nivell, pots ordenar les situacions i els elements que contenen i ajustar-ne les hores; les contribucions per competència es calculen a partir de les evidències o preguntes configurades. També pots editar les dades de l'assignatura i del nivell.
- A la taula de seguiment del nivell, marca un alumne com a exempt de tota l'assignatura. A la taula d'avaluació d'una activitat, marca l'exempció només per a aquella activitat; les exempcions s'exclouen de les qualificacions i dels resums, i es poden retirar en qualsevol moment.
- A l'informe d'assignatura de l'alumne, el percentatge avaluat de cada competència és el pes de les evidències o preguntes valorades dividit pel pes de tots els ítems programats per a l'alumne. El pes de cada ítem és la seva contribució a la competència multiplicada per les hores de l'element avaluable; s'exclouen els elements exempts i les classes sense avaluació.
- A «Seguiment diari», tria assignatura, grup classe o addicional i data per registrar per alumne la participació, la preparació, l'autonomia i la col·laboració, amb una observació opcional. Els alumnes exempts de l'assignatura no apareixen i cada alumne es pot marcar com a absent aquell dia (`absent: true`, sense nivells). A l'informe de cada assignatura de l'alumne es mostra l'historial de l'assignatura i la mitjana sobre 4 dels seus indicadors valorats; les absències i les observacions sense valoració no hi compten. Els registres es vinculen a l'assignatura, no a un nivell o curs acadèmic concret. Els canvis es desen automàticament i es conserven a les còpies JSON i de Google Drive.
- En el mode targetes del seguiment diari, després dels indicadors pendents de cada alumne present apareix una targeta d'observació, també quan ja hi ha una observació desada. Es pot editar el text i arrossegar la targeta en qualsevol direcció per desar-lo; «Desfés» recupera l'observació anterior. «Salta» manté el text pendent mentre el mode targetes és obert.
- A l'historial de seguiment de l'informe d'una assignatura de l'alumne, «Importa CSV» permet afegir valoracions per a aquella assignatura. El fitxer UTF-8 admet separadors de coma, punt i coma o tabulador i una capçalera opcional `dia,participació,preparació,autonomia,col·laboració,observacions`. Si la primera fila no és una data vàlida ni una capçalera reconeguda, es demana confirmació abans d'ometre-la; les columnes han de seguir sempre l'ordre indicat. Cada fila conté una data `DD/MM/AAAA`, valoracions `NA`, `AS`, `AN` o `AE` i una observació opcional de fins a 500 caràcters. Cal valorar almenys un indicador per fila; els altres poden quedar buits. També s'admeten els fitxers anteriors amb data `AAAA-MM-DD`, nivells de l'1 al 4 i sense columna d'observacions. Els dies repetits dins del fitxer i les dades invàlides impedeixen tota la importació. Si un dia ja existeix, es demana confirmació per substituir tots els seus indicadors (els camps buits els eliminen), conservant-ne l'observació existent encara que el CSV en contingui una altra, i anul·lant-ne l'absència si n'hi havia.
- Crea perfils d'alumnes amb els noms i cognoms en camps separats, i consulta el banc de competències.
- Consulta i edita el perfil docent des de l'element inferior de la barra lateral; el resum mostra alumnes, grups, assignatures, activitats, evidències avaluades i seguiments del curs vigent, amb una visualització de l'activitat dels darrers sis mesos.
- El banc de competències (`data/competency-bank.json`, editable a mà) s'inclou amb l'aplicació i és comú a tots els usuaris. Cada competència conté resultats d'aprenentatge amb la seva descripció i els seus criteris d'avaluació. Pots cercar-hi, crear-ne de pròpies i editar-ne tota la informació a la pàgina de la competència; només es desen les pròpies i les modificades del banc (es poden restaurar).
- Al perfil de cada alumne, consulta els nivells d'assignatura vinculats al seu grup actual i la nota mitjana de cadascun. Obre una targeta per veure el report de l'assignatura, amb el progrés per competència i el detall de cada activitat i les seves evidències.
- Crea activitats o proves al banc de planificació, independentment de l'alumnat. Afegeix les competències i els pesos de contribució dels ítems des d'un desplegable. Un element només mostra alumnat quan forma part de la seqüència d'un nivell amb una oferta docent vigent.
- En obrir una activitat, consulta la rúbrica d'evidències, les competències a què contribueix cadascuna i el seu progrés; en obrir una prova, consulta les preguntes i el solucionari per pregunta. A sota, registra el nivell assolit per cada alumne i ítem.
- La rúbrica de l'activitat s'edita en una pàgina independent. Per cada evidència s'hi vinculen una o més competències i s'hi defineix el criteri observable dels nivells NA, AS, AN i AE; els descriptors també apareixen als exports PDF/CSV/TSV i als informes de l'alumnat. El solucionari de la prova es defineix per pregunta i s'exporta amb les preguntes i competències associades, sense crear una rúbrica.
- El resum de l'activitat mostra la mitjana, mediana, percentatge d'aprovats i alumnat avaluat, així com la distribució real de notes en comparació amb una campana de Gauss de referència. Un alumne només compta com a avaluat quan té una qualificació registrada a totes les evidències de l'activitat. Cada punt correspon a un alumne i en mostra el nom i la nota en passar-hi el cursor.
- Obre l'informe resum d'un alumne clicant el seu nom a l'avaluació d'una activitat o una activitat del seu perfil. A l'informe pots escriure una retroacció específica per a l'alumne, que es desa amb la seva avaluació i també apareix al PDF. Des de l'informe pots exportar un PDF individual; des de l'avaluació de l'activitat pots descarregar un ZIP que conté un PDF independent per alumne de l'oferta. Els fitxers es generen localment al navegador. Les opcions d'exportació CSV, TSV i PDF s'agrupen al botó «Exporta».
- Pots canviar el tipus d'un element avaluable entre «Activitat» i «Prova» des de l'edició. La conversió conserva els identificadors dels ítems i les notes registrades; les dades específiques (criteris d'assoliment i solucionari) es mantenen per permetre convertir-lo de nou. Les proves antigues amb evidències es migren a preguntes i l'antic descriptor AE es proposa com a solucionari inicial.
- Qualsevol element sense preguntes o evidències és no avaluable: no genera qualificacions ni compta en les mitjanes.
- Les classes magistrals són elements de la seqüència (títol i hores, sense activitat) que s'avaluen amb el seguiment diari; no compten en les qualificacions per hores.
- Una activitat es pot marcar com «Activitat en grup» en crear-la o editar-la; només llavors mostra la secció d'agrupaments (nom i membres, un agrupament per alumne). El commutador «Individual / En grup» decideix la qualificació: en mode grup tots els membres reben la mitjana de les avaluacions individuals dels components; les avaluacions individuals no es modifiquen.
- Des de l'activitat pots exportar l'avaluació de l'oferta seleccionada com a CSV (separat per punt i coma, decimals amb coma) o TSV, amb nivell i nota de cada evidència, nota d'activitat, qualificació textual i estat, per importar-la a un full de càlcul. Si l'activitat és de grup, també pots exportar CSV/TSV amb les mitjanes per evidència i activitat de cada agrupament, o un informe PDF per agrupament amb els membres i el progrés mitjà.
- Els botons «Exporta» són a la capçalera de la seva secció: la rúbrica es pot exportar com a PDF, CSV o TSV; l'avaluació de l'alumnat, com a informes PDF o CSV/TSV; i els agrupaments, com a informes PDF per grup o CSV/TSV.
- Totes les exportacions PDF tenen format DIN A4: els informes d'alumnat i agrupaments s'imprimeixen en vertical, i les rúbriques i fitxes d'avaluació en apaïsat.
- Des de la secció d'agrupaments es poden generar fitxes PDF individuals per a l'alumnat en DIN A4 apaïsat. En generar-les es pot activar o desactivar l'autoavaluació, la coavaluació dels membres del seu agrupament i l'avaluació de l'actuació docent. Cada fitxa intenta encabir la rúbrica sencera en una pàgina; si no hi cap, continua a les pàgines següents, i deixa espai per a comentaris.
- La suma dels pesos de les evidències o preguntes mostra un avís si no és del 100%, perquè puguis revisar les contribucions assignades.
- A la taula d'avaluació d'una activitat, cerca alumnes o grups, filtra per grup i estat (avaluats, pendents, aprovats o no assolits) i ordena per nom, grup o nota. La barra de cerca i la barra horitzontal es mantenen fixes a la part superior mentre et desplaces per la llista.
- La llista d'activitats mostra per a cada targeta la nota mitjana, el percentatge d'aprovats (nota igual o superior a 5 entre l'alumnat avaluat) i el percentatge d'alumnes avaluats. Es pot obrir l'activitat fent clic a qualsevol punt de la targeta.
- Edita les competències i els detalls dels elements avaluatius. Les avaluacions existents es mantenen per als ítems que conservis; si n'elimines un, també se n'eliminen les notes.
- Registra el nivell assolit per alumne i ítem. La nota de l'element pondera les evidències o preguntes per la suma dels seus pesos de contribució a les competències; la nota de cada competència pondera els ítems pel pes configurat per a aquella competència.
- Les qualificacions fan servir un codi de color coherent als indicadors i desplegables: inferior a 5 (warning/no assolit), 5–6,9 (en procés), 7–8,9 (assolit) i 9–10 (avançat). L'alumnat amb una nota d'activitat inferior a 5 queda marcat com a warning.
- En avaluar una evidència, a més dels nivells de la rúbrica es pot marcar «No presentat»: compta com a avaluada i aporta 0 a la nota de l'activitat.
- Cada alumne pot marcar-se com a activitat «recuperada» (columna Rec.): la nota de les seves evidències, i per tant la de l'activitat i les competències, no pot superar 5/AS.
- La columna «Retroacció» de la taula d'avaluació permet desar comentaris per alumne i element avaluable; aquests comentaris també apareixen als informes exportats.
- Sempre que es mostra una qualificació, s'hi inclou la nota sobre 10 i la sigla textual corresponent: NA (<5), AS (5–<7), AN (7–<9) o AE (9–10). A la taula d'avaluació de cada activitat, el nom de l'alumne i la seva nota d'activitat queden fixos en desplaçar-se horitzontalment.
- Les dades s'emmagatzemen en format JSON a `localStorage` del navegador. Fes servir **Exporta JSON** per desar una còpia i **Importa** per restaurar-la o traslladar-la.
- Les dades de la versió 1 s'actualitzen automàticament a l'esquema 2 quan es carreguen. La migració crea el curs vigent, matrícula l'alumnat als grups actuals i transforma les assignacions de grup dels nivells en ofertes docents; les qualificacions existents es vinculen a les ofertes corresponents.
- La interfície utilitza les icones d'Iconoir CSS 7.12.1, carregades des de jsDelivr; cal connexió a internet perquè es mostrin.

## Dades i privacitat

Per defecte, aquest prototip no té servidor ni sincronització automàtica entre dispositius. Les dades es desen al navegador; esborrar-ne les dades pot eliminar-les. Fes servir **Exporta JSON** per desar còpies. Evita introduir dades personals sensibles de l'alumnat i comprova les polítiques de protecció de dades del centre.

## Format de dades

Els JSON exportats també poden incloure les col·leccions `dailyAssessments`, `subjectExemptions` i `activityExemptions`, amb els seguiments diaris i les exempcions per alumne. Els fitxers antics sense aquestes col·leccions es migren automàticament amb llistes buides.

Els JSON exportats contenen `schemaVersion: 2` i les col·leccions `classGroups`, `additionalGroups`, `students`, `competencies`, `activities`, `subjects`, `assessments`, `dailyAssessments`, `subjectExemptions` i `activityExemptions`. Un element avaluable «Activitat» desa `evidences`; una «Prova» desa `questions`. Cada ítem conté `contributions`, amb el pes específic per competència. El pes de l'ítem en el càlcul de l'element és la suma de les seves contribucions. Les preguntes tenen `answerKey` en lloc de descriptors de nivells; les dades de conversió guarden els camps específics de cada tipus per permetre una conversió reversible. Les dades antigues de proves que empraven `evidences` es migren automàticament a `questions`, mantenint els identificadors que referencien les notes; les dades antigues amb `criteria` també es migren a preguntes o evidències segons el tipus. Cada assignatura conté nivells amb competències i seqüències independents; cada nivell desa a `situations` una llista de situacions, cadascuna amb un `id`, un `name` i una llista `activities`. Cada element de la seqüència té un `id`, `activityId` i `hours`; les contribucions per competència es calculen sumant les contribucions dels ítems i ponderant-les per les hores. La resta de camps històrics (grups addicionals, matrícules, exempcions i nivells) es migren automàticament com abans. L'esquema versionat facilita afegir més endavant una API i persistència al núvol.
